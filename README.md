# FS_Lab · مختبر C++ التفاعلي

**جرّبه مباشرة:** https://fs-cpp-lab.netlify.app

اكتب كود C++ وشاهد تنفيذه خطوة بخطوة مع الشرح بالعربي: الذاكرة، والشروط، وجدول التتبع، والكونسول.
إعداد م. فرج الأحجل · FS Courses.

## ماذا يوجد فيه
- **27 درسًا** في برمجة 1 وبرمجة 2 وهياكل البيانات، وتُضاف دروس جديدة تباعًا.
- **تنفيذ خطوة بخطوة** مع إمكانية الرجوع، والانتقال إلى أي خطوة من شريط الخطوات، ومتابعة العمل من حيث توقفت.
- **رسم الذاكرة**: المتغيرات، والمصفوفات، والمؤشرات، و`new`/`delete`، والقوائم المترابطة، والأشجار.
- **+315 سؤال اختبار ذاتي** و**+120 سؤالًا مقاليًا** يُصحَّح حلّها تلقائيًا.
- يعمل كله داخل المتصفح، ولا يُرسَل الكود إلى أي خادم.

## التشغيل على جهازك
```
python -m http.server 8765
```
ثم افتح http://localhost:8765

## للمطورين
- `js/interpreter.js` مفسّر C++ مكتوب خصيصًا للموقع (جزء من اللغة يغطي مواضيع المقررات).
- `js/lessons*.js` الدروس، و`js/quiz*.js` الأسئلة.
- الاختبارات: `node tests/run_tests.js` و`node tests/check_lessons.js` و`node tests/check_quiz.js`.
